Lightless Auto Pair 0.1.3.0 update

This update adds /lap as the primary command while keeping /lightautopair as a legacy alias.

1. Extract this ZIP.
2. Open https://github.com/Surlako/Lightless-Auto-Pair
3. Choose Add file -> Upload files.
4. Upload all project files from this ZIP to the repository root.
5. Commit the replacements.
6. Open Actions -> Build and publish plugin -> Run workflow.
7. Wait for the green checkmark and confirm release v0.1.3.0 exists.
8. Update Lightless Auto Pair through /xlplugins.

The .github workflow does not need to be uploaded again.
